# Blender learning milestones

学習計画は[`docs/blender-learning-plan.md`](../../docs/blender-learning-plan.md)を参照してください。

各課題では、作業中の連番ファイルを`blender/work/`に保存し、合格条件を満たしたマイルストーンだけをこのディレクトリへ追加します。

推奨構成:

```text
01-fundamentals/future-can/
02-billboard/
03-companion-robot/
04-sculpt-mascot/
05-simple-character/
```

マイルストーンには次を含めます。

- Git LFS管理の`.blend`
- GitHub上で確認できる軽量プレビュー
- 学んだ操作、制作時間、未解決点、次の改善を記録したREADME
